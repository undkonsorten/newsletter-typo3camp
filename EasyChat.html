Why EasyChat?

Chatbots are everywhere – but at what price?

Typical SaaS chatbot

  • Conversations are processed outside your infrastructure
  • Vendor lock-in to one platform
  • Recurring fees per seat, message or month
  • No control over the model or data storage

EasyChat

  • Chats stored only in your TYPO3 database
  • 100% open source, installed via Composer
  • No platform fees – you only pay your LLM
  • Choose any model – and switch whenever you like

The idea

Open source instead of SaaS. All you need is TYPO3 and an LLM endpoint.

A lightweight AI assistant that lives inside TYPO3 – built on the values TYPO3 stands for: openness, flexibility and digital sovereignty.

Features

What EasyChat can do today – frontend, privacy, AI, knowledge and backend.

Features · Frontend

A chat widget editors can place anywhere

  • “Chatbot” content element – drop it on any page, configure it in the FlexForm
  • UI based on the open-source Deep Chat web component (or bring your own frontend)
  • Two templates: Default (inline) and Styled – floating toggle button, header, dismissable teaser bubble, colours via CSS variables
  • Fully customisable through Fluid template overrides and TypoScript
  • Configurable intro message and placeholder, translatable labels
  • Chat memory – the bot remembers earlier questions in the conversation

Features · Privacy & GDPR

Privacy by design

✓

3 consent modes

Built-in opt-in screen (with revoke), no consent needed, or hand over to your existing cookie manager.

⌂

Data stays home

Conversations are stored only in the TYPO3 database on your own server – no third-party chat platform.

⟳

Automatic cleanup

easychat:delete-sessions as a Scheduler task – e.g. keep chats for P3M, then delete them.

#

Minimal data

A random session ID (crypto.randomUUID()) and the messages – nothing more.

⏱

Cookie lifetime

Configurable per content element (default: 24 hours).

✕

Delete on demand

Editors can delete single sessions directly in the backend module.

✓ Approved by the data protection officers of PwC · in production use

Features · AI & models

Your model, your choice

  • Works with any OpenAI-compatible endpoint via Symfony AI
  • Model-agnostic: switch provider by changing one record – no code changes
  • Model dropdown is filled live from the provider’s /v1/models
  • System prompt per configuration – tone, rules, scope of your bot
  • Tool calling (similarity search), fault-tolerant against models that hallucinate tools
mittwald · gpt-oss-120b 🇩🇪 Mistral OpenAI self-hosted

Features · Knowledge (RAG)

Your TYPO3 content becomes the bot’s knowledge

  • Retrieval-augmented generation – answers grounded in your own website
  • Indexing via EXT:index, vectors in Qdrant, any embeddings model
  • The model looks things up itself via the similarity_search tool
  • Several bots with separate knowledge bases – one config, reaction and collection each
  • “Anything EXT:index can crawl becomes chat knowledge”

Features · Knowledge (RAG)

A knowledge base you can trust

👁

Public only

Only content an anonymous visitor could see is embedded. Access-restricted, hidden and time-limited pages are skipped.

↻

Always in sync

Deterministic chunk IDs update changed content in place; removed content can be synced out automatically.

⛨

Safety net

If a run would delete more than 25 % of the vectors, nothing is removed – an outage can’t wipe the knowledge base.

One field – Index configurations – decides what a chatbot knows. Hide a page and save: it’s gone from the bot.

Features · Backend & operations

Native TYPO3 all the way

  • Backend module – browse sessions, read full conversations, delete
  • CSV export of all or single sessions, pick the columns (questions, answers, system prompt …)
  • TYPO3 Reactions as the chat endpoint – secured with the reaction secret
  • Scheduler + CLI for data retention
  • Sessions also visible read-only in the List module
  • Optional log file var/log/easychat.log

Features · Setup

Up and running in minutes

Install

composer require undkonsorten/easychat

Configure LLM

Create an EasyChat configuration record: URL, API key, model, system prompt.

Add a Reaction

Create a TYPO3 Reaction of type EasyChat pointing to the configuration.

Place the chatbot

Add the Chatbot content element, paste reaction URL & secret. Done!

Optional extras: Scheduler task for cleanup · Styled template via static TypoScript · RAG with EXT:index + Qdrant.
